# Product scope

A developer/operator can deploy a private two-person calling and file-transfer example on one
Linux server. Four pages cover managed calls/chat, local media preflight, file acceptance and
support invitations. App access is private; authorized participants share a configured room.

The example demonstrates real Peerweave package consumption and production network concerns.
It does not provide self-service accounts, public room discovery, persistent chat/files, SFU
conferencing, recording, unattended publication or an availability guarantee.

Acceptance includes actual native media/data, failed authorization, stale credentials and
owned-resource cleanup. The [quality record](../QUALITY_SCORE.md) separates local from external evidence.
